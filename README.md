# 店舗用 12タイマー

## 主な機能
- 12個同時管理
- iPad横画面で4列×3段
- 30分 / 60分を大きく表示
- 15 / 45 / 90 / 120分プリセット
- 任意分数設定
- 終了予定時刻表示
- +30分延長
- 残り5分・1分で警告
- 終了時に赤表示 + アラーム
- タイマー名変更
- 自動保存
- PWA対応

## 重要
ChatGPTやiPadの「ファイルプレビュー」ではJavaScriptが動かず、タイマーが表示されない場合があります。
GitHub PagesなどでWeb公開したURLをSafariで開いてください。

## GitHub Pagesで公開
1. GitHubで新しいリポジトリを作成
2. このフォルダの index.html / manifest.webmanifest / sw.js をアップロード
3. Settings → Pages
4. Deploy from a branch を選択
5. main / root を選び Save
6. 発行されたURLをiPadのSafariで開く
7. 共有 → ホーム画面に追加

## Codexで改修するときの例
「この12タイマーアプリに、利用履歴のCSV出力を追加してください」
「タイマー終了5分前の音を3回鳴らすようにしてください」
「ホームランドーム松江店のロゴと青・黄カラーに合わせてください」
