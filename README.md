# iPad専用版
PC版とは別のGitHub Pagesリポジトリに全ファイルを公開してください。SafariでHTTPSの公開URLを開き、共有→ホーム画面に追加。追加したアイコンからオンラインで一度起動し、機内モードで再起動できるか確認してください。横向きで使用。設定→画面表示と明るさ→自動ロック→なし（選択可能な場合）。終了音は最初に画面をタップし、音量を確認。スリープ・バックグラウンド中の音は保証されません。日計はAirPrint対応プリンターで印刷。データは端末内のみでPCと同期しません。実機未検証のため営業前に確認してください。

更新: 横画面の余白を縮小し、終了カード全体を赤色に変更。

V3: ボタン・文字拡大。Safariの表示領域が狭い場合は操作ボタンが隠れないよう縦スクロール可能。終了時は受付終了ボタンを操作列に表示。
